Bouton pilule (gros arrondis). Primaire en dégradé lumineux + halo ; secondaire en verre dépoli ; accents teal/orange/corail. Léger soulèvement au survol.

```jsx
<Button variant="primary">Voir le comparatif</Button>
<Button variant="secondary" size="sm">Filtrer</Button>
<Button variant="teal">Trouver le mien</Button>
<Button variant="minium-outline">Signaler une erreur</Button>
```

Variants : `primary` (dégradé violet→teal), `secondary` (verre), `ghost`, `teal`, `minium` (dégradé orange→corail) et `minium-outline`. Tailles `sm | md | lg`. `as="a"`, `iconLeft`/`iconRight`, `fullWidth`.

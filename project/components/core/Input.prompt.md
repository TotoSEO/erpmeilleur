Champ de saisie sur blanc data, angle vif et filet hairline. Utilisez `mono` pour toute saisie chiffrée (budget, plafond).

```jsx
<Input label="Votre budget mensuel" suffix="€ / mois" mono placeholder="50" />
<Input label="Email" type="email" hint="Pour recevoir le verdict" />
```

Props : `label`, `hint`, `error` (passe le filet au minium), `prefix`, `suffix`, `mono`.

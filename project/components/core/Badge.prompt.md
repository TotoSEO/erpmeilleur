Pastille / sticker de statut ou de verdict ; vert = positif, corail = négatif/alerte, violet = marque, teal/orange = accents. Utilisez `mono` pour les versions, dates et compteurs.

```jsx
<Badge tone="positive" variant="pop" dot>Recommandé</Badge>
<Badge tone="negative" variant="gradient">À éviter</Badge>
<Badge tone="blue" mono variant="outline">v2026-06</Badge>
<Badge tone="teal" variant="soft" mono>37 testés</Badge>
```

Tones : `neutral | blue | teal | orange | positive | negative`. Variants : `soft | outline | solid | gradient | pop` (pop = bordure épaisse + ombre décalée). `dot` ajoute une puce de statut.

Notation par faders : un curseur physique sur rail gradué, comme une console. Remplace la barre de progression. Couleur selon le seuil (teal ≥ 7, violet 5–7, sunset < 5). À poser dans un `GlassPanel`.

```jsx
<Faders items={[
  { label: 'Prise en main', value: 8.8 },
  { label: 'Qualité-prix', value: 8.4 },
  { label: 'Support FR', value: 7.2 },
]} />
```

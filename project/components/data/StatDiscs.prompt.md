Disques de chiffres clés qui flottent en couches : chacun porte son ombre et un léger angle, créant le relief. 2 à 4 disques, à poser dans un `GlassPanel`.

```jsx
<StatDiscs items={[
  { value: '8,4', unit: '/10', label: 'global' },
  { value: '14,90', unit: '€', label: '/ mois' },
  { value: '14', unit: 'j', label: 'essai' },
]} />
```

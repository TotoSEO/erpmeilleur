Graphique éditorial clair : grille douce, aire dégradée, ligne dégradée flash, point d'inflexion optionnel. Posé sur verre, jamais sur écran noir.

```jsx
<Chart title="Courbe d'adoption" caption="21 jours · plateau dès J+3"
  values={[10, 18, 42, 70, 82, 86, 88, 90]} highlight={3} />
```

Props : `values` (nombres), `max`, `highlight` (index du point marqué), `title`, `caption`.
